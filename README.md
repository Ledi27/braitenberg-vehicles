# Braitenberg Vehicles

A Python + Pygame simulation of Braitenberg Vehicles — simple autonomous agents from Valentino Braitenberg's 1986 book *Vehicles: Experiments in Synthetic Psychology*.

## What's included

- **base.py** — Vehicle 2 simulation: a two-sensor agent that steers toward or away from a light source
- **vehicle.py** — Vehicle 5 simulation with threshold logic gates (OR, AND, NOT) wired to motor outputs

## Requirements

```
pygame
```

Install with:

```bash
pip install pygame
```

## Running

```bash
python base.py
python vehicle.py
```

## Reference

Braitenberg, V. (1986). *Vehicles: Experiments in Synthetic Psychology*. MIT Press.
